# 05 · 升降桌专项

升降桌的运动、支撑、控制与安全取决于**具体外购升降系统**，不能只凭铝型材框体的形状确定。型材可以承担台面承托和连接功能，但外购柱、顶板、底座、控制器及其连接应作为完整系统选型。

## 系统分解

| 子系统 | 需要取得的资料 |
|---|---|
| 升降柱与驱动 | 型号、行程、缩回和伸出总高、动态/静态载荷、偏载限制、工作周期 |
| 顶部安装板与转接件 | 外形、孔距、孔径/螺纹、材料、安装面与螺栓啮合要求 |
| 型材框体 | 型材截面、梁位、连接件、台面支承与工具可达性 |
| 台面与固定件 | 材料、板厚、悬挑、孔位、完整固定组合及抗拔要求 |
| 底座与地面接触 | 前后支撑跨度、调平、重心与倾覆风险 |
| 控制与布线 | 同步、限位、碰撞保护、电气防护、线缆全行程余量 |

**先选定升降系统并拿到图纸，再布置框体与转接件。** 双柱载荷不能由单柱额定值直接乘二，最高位稳定性、偏载与控制策略也不能从柱数推断。

## 高度与行程

桌高应从地面接触点逐层计算：底座、升降柱实际安装高度、顶板/转接板、框体叠放关系和板厚。框体可能与顶板齐平，也可能叠在顶板上，不能无条件把各项厚度全相加。

```text
最低桌高 = 按缩回态安装图逐层计算的台面最高点
最高桌高 = 按伸出态安装图逐层计算的台面最高点
```

人体工学高度依身高、坐姿、设备与使用习惯确定；两节或三节柱是否满足要求，应核对实际缩回高度与行程，不以节数作保证。

`meta.heightRange` 只是设计标注，不会让 3D 自动升降，也不是可用行程认证。空心外购件必须用实际 `massKg` 覆盖，避免按实心包围盒估重。

## 框体与安装接口

闭合框、横撑、连接板和斜撑各有作用，但不能宣称某种外形固定带来“一个数量级”刚度提升，或“没有某根撑一定会晃”。连接刚度、柱的间隙、底座跨度、偏心载荷及最高位工况都应分析。

### 升降柱不是 T 槽型材

钢制方管或伸缩柱表面没有自动出现的 I8 槽。**不能用一组槽内 T 螺母，把普通钢柱当成铝型材连接。**

- 优先使用厂家规定的顶部安装板与孔位；孔距不匹配时设计经过核对的转接板。
- 侧装或加撑仅在厂家允许的固定安装区域进行，不得夹紧、打穿或阻挡伸缩滑动面。
- 转接板、焊接件、夹具或开孔都需要单独材料、尺寸与工艺，不属于“多加角码即可完成”。
- 全行程检查线缆、框梁、螺栓突出量、夹点、底座和控制器的干涉。

### 下料与连接

外置角码通常不夹在端面间，不应额外扣除“两端角码占位”。横梁夹于两根等宽立柱内侧时，长度等于柱中心距减去柱宽；若支撑对象为不同尺寸的钢柱与顶板，应按真实面位置计算，不能套用 40mm 型材公式。

## 厚台面固定

25mm 木台面不能直接嵌进针对 5–10mm 薄板的 PVC 压条。可选择底面角码配木螺钉、螺纹嵌件、专用支架或穿板螺栓，需同时明确：

- 台面由哪些梁承托，固定点的位置与边距；
- 型材侧的槽型螺母和螺栓；
- 板侧螺钉、嵌件或螺母及垫片；
- 孔径、沉孔/预钻孔、实际入木深度、不得穿面；
- 板材抗拔、局部承压、湿度变形和重复拆装要求。

新固定工作台的 `panel-i8-kit` 仅演示完整记录方式，未验证的木螺钉尺寸与板材强度不能直接作为升降桌设计依据。框体角码数量也不等于台面固定件数量。

## 旧 `standing-desk.json` 连接审查

旧文件作为兼容设计保留，**本次不迁移、不补出虚构安装实例，也不宣称其已具备可制造连接**。

| 问题 | 从现有数据得到的事实 | 需要补充的工作 |
|---|---|---|
| 中横撑两端各有 6mm 间隙 | 两根内管中心 `x=±500`、宽 68mm，内侧面在 `x=±466`；920mm 横撑端点在 `x=±460`，每侧差 `466−460=6mm` | 明确真实固定对象与接口，不能靠角码自动填补；若仍接外管，间距又不同 |
| 缺顶部安装板/转接件 | 文件只有柱管占位、框梁和台面，未记录实际顶板几何与孔距 | 取得型号图纸，补完整顶板/转接设计与紧固方式 |
| 钢柱没有 T 槽 | `column` 是钢制伸缩管占位，不是 I 型槽 8 型材 | 不可把 `tnut-m8` 用作钢柱侧面槽内固定，须采用厂家认可接口 |
| 板固定缺件 | 清单有 8 只 `spring-tnut-m8`，没有对应完整板侧螺栓/支架/木螺钉/垫片或加工要求 | 另建完整板固定方案，不能只凭螺母数量确认 |
| 端盖备注方向写反 | 前后长梁沿 X 通长，两端外露；沿 Z 的短梁两端抵在长梁内侧 | 旧备注“短边框外露端面”不正确，数量和安装对象应重新审查 |

旧模型的基本标注为：1400×700×25mm 台面、1300×620mm 框体、920mm 中横撑、720–1180mm 高度范围。型材下料总长为 `2×1300+2×540+920=4600mm`。这些数值描述文件，不是对旧 `loadRating: 120` 的独立验证；模型通过基础数据校验，也不能补足上述实物接口缺口。

## 制作前检查清单

- [ ] 取得升降系统型号、安装图、允许载荷与使用限制。
- [ ] 全缩、全伸与中间位置均无机械、电气或夹点干涉。
- [ ] 顶板、转接板、框体与柱体之间都有明确加工与紧固路径。
- [ ] 没有把钢柱侧面假定成 T 槽，未改动厂家禁止区域。
- [ ] 台面有独立完整固定件，孔位、板厚与入木深度已复核。
- [ ] 下料算式、端面接触和实际间隙一致，连接件不会悬空。
- [ ] 底座跨度、重心、偏载和最高位稳定性已核对。
- [ ] 质量、载荷、预紧与防松数据来自实际产品或计算，不从可视化推导。

连接表达方式可参考 [07 典型 DIY 示例与连接审查](./07-典型DIY示例与连接审查.md)，但固定工作台、置物架和开放围框不是升降桌替代设计。
