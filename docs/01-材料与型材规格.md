# 01 · 材料与型材规格

## 铝合金牌号

铝型材几乎只用 6 系铝合金，因为可挤压 + 可阳极氧化。

| 牌号 | 特点 | 用在哪 |
|---|---|---|
| **6063-T5** | 最主流。表面质量好，氧化后色泽均匀，强度中等 | 90% 的工业铝型材 |
| 6061-T6 | 强度高约 30%，切削性好，但氧化色泽偏暗 | 承重要求高、需攻牙的场合 |
| 6005A-T5 | 强度高于 6063，适合薄壁大截面 | 汽车、轨道车辆 |

**默认选 6063-T5。** 只有在明确需要更高强度、或要做重载螺纹连接时才考虑 6061。

`T5` 是状态代号：挤压后风冷 + 人工时效。别写成 T6（那是水淬，薄壁件会变形）。

## 惯性与跨度的关系

惯性矩 I 决定抗弯刚度。简支梁在均布载荷下的挠度：

```
δ = 5·q·L⁴ / (384·E·I)

q = 均布载荷 (N/mm)
L = 跨度 (mm)
E = 弹性模量，铝约 69,000 N/mm²
I = 惯性矩 (mm⁴)
```

注意 **L 是四次方**。跨度翻倍，挠度变成 16 倍 —— 这就是为什么跨度决定截面，而不是载荷。

实用判断：

| 跨度 | 4040 的挠度（q=1 N/mm） | 结论 |
|---|---|---|
| 600mm | 0.03mm | 可忽略 |
| 1000mm | 0.15mm | 基本无感 |
| 1500mm | 0.76mm | 肉眼可见轻微下垂 |
| 2000mm | 2.4mm | 明显下垂，需要加中撑或换 4080 |

一般桌面允许 1mm 以内的下沉。超过就该换截面或加支撑。

## 公差

工业铝型材的常见公差：

- 截面尺寸：±0.2mm
- 直线度：≤ 1mm / m
- 长度：±0.5mm（精切可到 ±0.2mm）
- 扭曲度：≤ 1° / m

**设计时要留间隙。** 需要滑配的场合（如板材嵌入槽内）至少留 0.5mm。

## 表面处理

| 处理 | 特点 | 适用 |
|---|---|---|
| **阳极氧化（银白）** | 最主流。耐磨、绝缘、外观中性 | 默认选这个 |
| 阳极氧化（黑色） | 同上，深色 | 视觉要求高的场合 |
| 喷砂阳极氧化 | 哑光质感，指纹不明显 | 桌面、展示类 |
| 喷粉（粉末喷涂） | 颜色自由，膜厚大（60-100μm） | 需要特定颜色时 |

**注意**：喷粉会略微增加截面尺寸（每面 ~50μm），需要精密配合的槽口可能受影响。

## 写进 design.json 的 material 字段

`material` 是纯标注，但请写完整，它决定了渲染颜色和文档可读性：

```json
"material": "6063-T5 银白阳极氧化"
"material": "6063-T5 黑色阳极氧化"
"material": "钢制喷粉 深灰"
"material": "枫桦木多层板"
```

渲染器按关键词匹配颜色（见 `src/lib/materials.ts`），所以用词要包含关键特征：`铝` / `6063` / `钢` / `木` / `喷粉` / `黑` / `深灰`。
