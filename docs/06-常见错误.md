# 06 · 常见错误

按接口、几何、装配与数据维护逐层检查。几何相碰、数据通过校验或清单数字凑齐，都不代表完成制造与安全评审。

## 接口与计数错误

### 1. 只按“4040”“欧标”或“M8”购买五金

4040 只说明外形，M8 只说明螺纹；槽宽、槽深、槽腔、角码定位凸台和孔位仍可能不同。“欧标”不是唯一的 6.2mm 槽口或 8.2mm 槽腔标准。

**正确做法**：确认具体产品体系、料号、截面图和适配表。三例统一 `4040-i8` / `i-slot-8`，不与旧 `4040` 槽型假设混用。软件 family 标签仍不代替跨品牌实物尺寸核对。

### 2. 把“每个角必须两个角码”当作通则

角码数量与连接件类型、连接对象、布置、预紧和载荷相关，不能断言单角码一定“一推就转”，也不能说双角码一定安全。

**正确做法**：逐一列出连接的构件对。本次三例为两圈共八根梁，每根两端各一套，共 16 套结构角码；台面和层板另外计固定套件。需要增加斜撑或连接板时，应重新分析实际受力。

### 3. 套件与散件重复计料，或只列一半固定件

`bracket-i8-kit` 一套内已有一只角码、两颗 M8×16、两只 I8 M8 T 螺母。若再添加同一连接用的散件，会重复计数；反之，只为木台面列 T 螺母而缺板侧螺钉、垫片或支架，也没有完成连接。

**正确做法**：按完整组合计套数，再展开核对采购明细；`instances` 只定位套件，不能作为第二份收费数量。

### 4. 认为 8.2mm 中心孔能直接攻 M8

⌀8.2mm 不是常规切削 M8×1.25 的底孔，常用底孔约为 6.8mm，具体仍按材料与加工工艺。供应商说“芯孔可加工 M8”不等于已攻牙，也不能从旧渲染参数推导制造尺寸。

### 5. 宣称螺栓必须 304，或者 M8×20 是所有 4040 的标准长度

镀锌钢是实际槽内紧固件常用的材料方案；不锈钢也可能与铝形成电偶。螺栓长度取决于角码、垫片、槽深与螺母，过长可能顶底，过短则啮合不足。

**正确做法**：按供应商的材料等级、表面处理、环境和啮合要求选型。本次 Motedis 二孔角码参考选配为 DIN 912 M8×16，仅适用于核对后的组合。

## 几何与结构错误

### 6. 没按实际端面关系下料，或额外扣两端角码占位

外置角码通常贴在转角空腔中，不夹在端面之间，不需要机械地“再减两只角码厚度”。

四柱结构的横梁夹在两根等宽 40mm 立柱内侧时：

```text
宽向梁 = 外廓宽 − 2×40
深向梁 = 外廓深 − 2×40
```

前后长梁通长、短梁夹在其间时，则短梁按**外廓深**减两倍长梁截面宽，不能错误地沿外廓宽计算。专用接头或工艺间隙确实位于端面之间时才按图另扣；引擎不自动做下料扣减。

### 7. 只放大型材，忽略接头、挠度和稳定性

跨度、载荷、连接刚度、底座支撑和重心都影响结果。不能脱离载荷和边界条件断言“跨度到某值一定挠多少”，也不能一概说闭合框比另一种框强一个数量级。

**正确做法**：根据集中/分布载荷、实际跨度与支撑方式核算挠度、滑移、扭转和倾覆。上层偏载、使用者推拉或设备振动可能需要独立锚固。

### 8. 把板材接触、刚好不相交当作安装公差

模型中零间隙贴合有助于表达关系，不代表锯切、板材胀缩和实际插入路径都允许零间隙。反之，悬空间隙也不能自动由角码补足。

**正确做法**：采购图中单列公差、安装间隙与工艺，并同步实际尺寸和备注。旧升降桌中横撑两端各 6mm 的间隙是尚未解决的接口问题，不应掩盖，见 [05 升降桌专项](./05-升降桌专项.md)。

### 9. 把厚木板装进薄嵌板压条

针对 5–10mm 板的 PVC 压条不能直接用于 15mm 层板或 25mm 台面，按四边周长买压条也不会自动形成可靠的厚板支承与固定。

**正确做法**：选完整底面支架、嵌件或穿板方案；核对板侧孔径、头型、垫片搭接、预钻与入木深度、握钉力和不得穿面。

## 装配与外购件错误

### 10. 以为带弹片的螺母一定可以槽口后装

弹片通常保持位置，能否后装取决于具体螺母结构。有些要从端部滑入，有些可旋入或翻转。

**正确做法**：核对产品安装路径，并在封闭端头前预装需要的螺母；同时检查内置件、面板和工具的槽内空间。

### 11. 把普通钢柱当作带 T 槽的铝型材

升降柱管体没有自动存在的槽腔。不能仅靠角码和 T 螺母完成钢柱侧面连接，也不能在厂家禁止区域钻孔、夹紧或遮挡伸缩面。

**正确做法**：取得顶部安装板、底座和允许接口的图纸；需要转接板或固定夹具时，另列材料、加工和完整紧固件，并做全行程检查。

### 12. 漏掉顶板、转接件或工具空间

BOM 中有角码，不表示已有安装板；安装面贴合，不表示螺栓能装入或内六角工具能转动。

**正确做法**：按实际装配顺序检查预装、开孔、紧固、封盖与拆卸；加工尺寸以供应商 CAD 和图纸为准，不以示意角码模型测量。

### 13. 按所有型材端头一律计端盖

端面被相邻构件挡住、属于需预装螺母的通道或无法安装端盖时，不能套用“每根两个”。

**正确做法**：逐端核对外露与可安装性。旧升降桌外露的是前后长梁沿 X 的端面，短梁沿 Z 的端面抵在长梁内侧，旧备注“短边框外露”写反。

### 14. 空心外购件按实心包围盒估重

钢管、升降柱和脚轮按包围盒体积乘密度可能严重高估。

**正确做法**：在 `parts[].massKg` 记录单件实际重量或供应商数据，且说明来源。质量估算不能替代外购件载荷与稳定性限制。

## 数据维护错误

### 15. 混淆构件中心与角码安装原点

构件的 `position` 是中心点。角码实例的 `position` 则是两外安装面交线的中心，使用世界坐标。`partIds` 第一项对应局部 `x=0` 面、第二项对应局部 `y=0` 面，不是无序集合。

### 16. 只改采购数量，没改安装实例

有 `instances` 时必须 `qty === instances.length`，否则表单和共享校验都会拒绝。直接修改备注应保留全部实例；删掉一整行配件则会同时移除其连接，须明确确认。

### 17. 复制/镜像后误以为连接也复制了

构件复制和镜像仅新增构件，现有连接仍引用原 ID。几何编辑不会自动重布置角码；失效连接需要在高级 JSON 中显式调整。

### 18. 改尺寸没改 `note`，或拿 `material` 表达几何

`note` 的下料算式必须同步；`material` 仅作材料标注与渲染映射，不控制截面、孔位或承载。

### 19. 不运行数据校验，或把通过校验当作可制造认证

编辑后运行 `pnpm validate <id>`。校验覆盖已实现的数据和几何约束，不验证每颗螺栓、抗拔、疲劳、倾覆或加工可行性，不能从“通过”推导额定载荷。

## 采购前的最终检查

- [ ] 型材、角码与螺母属于明确匹配的接口体系，而不只是同为 4040 / M8。
- [ ] 所有固定点都有完整套件，实例数等于采购数，套内零件不重复计费。
- [ ] 材料、等级、表面处理、螺栓长度、啮合和防松按实际产品复核。
- [ ] 下料由端面关系决定，工艺间隙、角码占位与工具空间分别核对。
- [ ] 台面与层板固定件独立齐全，板厚、孔位与入木深度已复核。
- [ ] 外购柱的顶板孔距、允许安装区域与行程干涉已确认。
- [ ] 端盖、调平、锚固和未建模附件已按实际需要另列。
- [ ] 载荷、挠度、抗扭、抗拔和稳定性另行评审，不从示意模型推导。
