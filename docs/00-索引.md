## 选型速查

| 用途 | 推荐规格 | 说明 |
|---|---|---|
| 3D 打印机架、小型展示架 | 2020 | 跨度 < 500mm，轻载 |
| 工作台、书架、展示柜 | 3030 / 4040 | 30 系为常见性价比拐点 |
| 升降桌、设备机架 | 4040 | 承重与抗扭刚性均衡 |
| 大跨度横梁（> 1200mm） | 4080 | 抑制跨中下垂 |
| 重载龙门、自动化设备 | 4545 / 8080 | 高刚性重载 |

## 核心原则

1. **跨度决定截面**：简支梁挠度与跨度四次方（$L^4$）成正比，跨度翻倍挠度增至 16 倍。
2. **连接件数量优先**：单转角至少使用 2 个角码抗扭转，不要靠盲目放大型材弥补连接刚度。
3. **空心外购件单列重量**：升降柱、脚轮等外购件须在 `parts[].massKg` 标注实重，不可用包围盒体积乘密度估算。
4. **区分数据来源**：`data/catalog/profiles.json` 中的 `source` 区分 `supplier`（供应商手册实测）与 `estimate`（公开资料估算，当前默认值，采购前须核对）。
