# 03 · 连接方式

这是做铝型材框架最核心的知识。**选错连接方式，整个设计要推翻。**

## 五种主流连接

| 方式 | 强度 | 可拆 | 隐藏 | 成本 | 适用 |
|---|---|---|---|---|---|
| 外置角码 | 中 | ✅ | ❌ | 低 | **默认选择** |
| 内置角码 | 中高 | ⚠️难 | ✅ | 中 | 外观要求高 |
| 内嵌连接条 | 高 | ❌ | ✅ | 中 | 同轴接长 |
| 端面攻牙 + 螺栓 | 高 | ✅ | ✅ | 低 | 端面直接对接 |
| 沉头穿栓 | 中 | ✅ | 半 | 低 | 板材固定 |

---

## 外置角码（最常用）

**做法**：L 形角码贴在两根型材的外侧转角，每边 2 颗螺栓 + T 螺母。

```
     型材 A
   ┌─────────
   │
┌──┴──┐
│     │   ← 角码（贴在外部）
└──┬──┘
   │
   └─────────  型材 B
```

**优点**
- 便宜、易得、可反复拆装
- 装配时不需要预装，随时可加
- 强度够用（每角 2 颗螺栓）

**缺点**
- 外露，影响外观
- 占用槽口位置（装了角码的槽就不能装别的了）

**关键细节**
- 每个转角用 **2 个角码**（内侧 + 外侧，或上下两个）抗扭转。1 个角码的连接会绕轴转动。
- 螺栓长度选 20mm（M8×20），太长会顶到型材内壁
- 角码要选**与型材同系列**的。4040 的角码装不进 3030

**`accessories` 配置示例**

```json
{ "ref": "bracket-outer-4040", "qty": 8, "note": "四角各 2 个" }
{ "ref": "tnut-m8", "qty": 16, "note": "与角码螺栓配对" }
{ "ref": "bolt-m8x20", "qty": 16 }
```

## 内置角码

**做法**：角码完全嵌入型材槽内，从外面看不到。

**优点**
- 外观整洁，无外露五金
- 不占槽口位置

**缺点**
- **必须在装配前滑入槽内**，后期几乎无法加装
- 拆装困难，需要从端头退出
- 价格约为外置的 1.5 倍

**适用**：桌面外露边缘、展示类、需要精致外观的地方。

⚠️ **设计阶段就要定下来**。如果先按外置设计、做完想改内置，等于重做。

---

## 内嵌连接条

**做法**：一段带有双头螺栓的连接条插入两根型材的端面中心孔，拧紧后拉合。

**优点**
- 强度最高（沿轴向受力）
- 完全隐藏
- 接头处外观连续

**缺点**
- **不可拆**（或极难拆）
- 要求两根型材端面**精密切割**（垂直度差会歪）
- 只能用于同轴对接

**适用**：型材需要接长（超过标准 6m 长度）、或长边需要"看起来是一根"的场合。

**长度计算**

```
接长后的总长 = 段1长度 + 段2长度 − 连接条重叠量（约 20mm）
```

---

## 端面攻牙 + 螺栓

**做法**：在型材端面中心孔攻 M8 螺纹，螺栓从另一根型材的槽口穿过来直接拧进去。

**优点**
- 最便宜（不用买角码）
- 完全隐藏
- 可拆

**缺点**
- 需要攻牙（自己攻或让供应商攻，通常加 2-3 元/孔）
- 只能用于端面对接，不能做 T 型连接
- 螺纹在铝里强度有限，反复拆装会滑牙

**适用**：型材端头与另一根型材侧面垂直连接，且外观要求隐藏。

**注意**：铝的螺纹强度低，建议用**钢丝螺套**或不锈钢螺栓，避免电偶腐蚀。

---

## 沉头穿栓

**做法**：在板材上打沉头孔，螺栓穿过板材拧进槽内的 T 螺母。

**优点**
- 板材可拆卸、可更换
- 定位精确

**缺点**
- 板材要预先打孔（定位错了就废）
- 螺栓头外露（沉头可做得较平）

**适用**：木板、亚克力板等硬质板材固定到型材框架。

**替代方案**：用 `panel-strip-pvc`（板材压条）把板材嵌入槽内，完全不需要打孔。**优先考虑这个。**

## 连接方式与长度的关系

这是设计时最容易算错的地方。

### 框体转角

```
        总宽 W
   ┌─────────────────┐
   │                 │  ← 上下两根长梁，全长 = W
   │  ┌───────────┐  │
   │  │           │  │  ← 左右两根短梁，夹在中间
   │  └───────────┘  │
   └─────────────────┘
```

如果用外置角码（螺栓贴在外部转角）：

```
长梁长度 = W
短梁长度 = W − 2 × 型材截面宽 − 2 × 角码占位
```

如果四根梁 **端面齐平**（用内置角码或攻牙）：

```
长梁长度 = W
短梁长度 = W − 2 × 型材截面宽
```

**差的就是角码占位那几十毫米。** 这个必须在 `note` 里写清楚。

### 立柱与横梁

```
        横梁（长度 = 两立柱内侧间距）
   ┌────────────────┐
   │                │
  ██                ██   ← 立柱
```

```
横梁长度 = 立柱中心距 − 型材截面宽
```

如果横梁跨在立柱外侧（如桌面框体），则：

```
横梁长度 = 立柱中心距 + 型材截面宽
```

## 选型决策树

```
需要转角连接吗？
├─ 是 → 外观重要吗？
│        ├─ 重要 → 内置角码（设计阶段就定）
│        └─ 不重要 → 外置角码（默认，2 个/角）
└─ 否 → 是同轴接长吗？
         ├─ 是 → 内嵌连接条
         └─ 否 → 端面对接 → 攻牙 + 螺栓
```

## 常见错误

1. **每个转角只用 1 个角码** —— 会扭转，一推就晃
2. **角码和型材系列不匹配** —— 装不上
3. **先设计后想想用内置角码** —— 要重做
4. **螺栓买长了** —— 顶到型材内壁，拧不紧
5. **没算角码占位，梁做长了** —— 装不进去
