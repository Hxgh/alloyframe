# 06 · 常见错误

按"会毁掉整个设计"到"只是难看"排序。

## 致命错误

### 1. 角码和型材系列不匹配

买 4040 的型材配 3030 的角码。装不上，或者勉强装上但吃不住力。

**核对方法**：角码产品页会写"适配 4040"。一次买齐，不要混牌。

### 2. 每个转角只用 1 个角码

L 形角码只在一个平面内约束。单角码的连接能绕轴转动 —— 框架一推就晃，而且**拧多紧都没用**。

**正确做法**：每个转角 2 个角码，分布在两个平面上。

```
   正确                          错误
  ┌──┐                        ┌──┐
  │▣ │  ← 上平面 1 个          │▣ │  ← 只有 1 个
  │  │                        │  │
  └──┘                        └──┘
  侧面再 1 个（看不见）          一推就转
```

### 3. 空心的外购件按实心算重量

升降柱是薄壁钢管，实物 3.5kg，按包围盒 80×300×50 × 钢密度 7850 算出来是 9.4kg。**差 2.7 倍。**

后果：算料单重量虚高，选脚轮/评估搬运重量时全部失真。

**解决**：给这类零件写 `massKg` 实测值。

### 4. 忘了端头扣减

1400 的桌，前后主梁做 1400 —— 装上去发现左右端梁装不进去。

**正确**：主梁 1400，端梁 = 1400 − 2×40（型材宽）− 2×角码占位。

### 5. 用碳钢螺栓配铝型材

电偶腐蚀。铝和钢在有水汽的环境下形成原电池，钢螺栓锈死，铝型材孔蚀。

**必须用 304 不锈钢。**

## 结构问题

### 6. 跨度太大没加中撑

一根 4040 跨 2000mm，均布载荷下挠度约 2.4mm。放书、显示器会明显下沉，而且长期会塑性变形。

**判断**：跨度 > 1200mm 就该考虑加中撑或换 4080。

### 7. 框架不是闭合的

只有两根梁连接立柱，没有端梁闭合。扭转刚度差一个数量级 —— 桌面会前后扭。

**正确**：做成"口"字闭合框。

### 8. 悬挑过大

台面比框体宽 200mm，手肘压上去边缘会明显下垂。

**建议**：左右悬挑 ≤ 100mm。

### 9. 只靠一根立柱

单柱升降桌的采购目的通常是省空间，但扭转刚度差很多。如果桌面宽度 > 1000mm，**必须双柱**。

## 装配问题

### 10. 用标准 T 螺母装后期配件

标准菱形 T 螺母只能从型材**端头**滑入。框架装好之后再加配件，螺母进不去。

**解决**：能预估位置的用标准螺母，不能预估的用**弹片螺母**（可从槽口任意位置压入）。

### 11. 螺栓买长了

M8×25 的螺栓装进 40mm 型材，顶到对面内壁，拧不紧还压坏型材。

**4040 的标准长度是 M8×20。**

### 12. 内置角码装反了时机

内置角码必须**在装配前**滑入槽内。装完框架才想起来要加，只能全部拆掉重来。

### 13. 忽略了升降柱的伸缩面

角码装在升降柱内管的滑动面上，升降会刮擦、异响、甚至卡死。

**升降柱的四面中至少有一面是滑动面，不能装东西。**

## 加工问题

### 14. 端面切割不垂直

内嵌连接条要求两根型材端面垂直度极高。斜切 1° 在 1000mm 长度上就是 17mm 的偏斜。

**解决**：让供应商用专业切割机切，别自己用角磨机。

### 15. 忘了攻牙

端面攻牙要在下料时一起做（供应商通常收 2-3 元/孔）。事后自己攻，没有台钻很难保证垂直。

### 16. 板材要嵌入却没算压条厚度

用板材压条后，槽口的有效宽度减少约 1mm。板材太厚插不进去。

**买压条前先确认板材厚度。**

## 数据维护错误（针对本项目）

### 17. `position` 写成端点坐标

本项目 `position` 是**中心点**。写成端点会导致零件整体偏移半个尺寸。

### 18. 改了尺寸没改 `note` 里的算式

`note` 里的算式是下一个人理解原始意图的唯一线索。不更新会导致后续改动全部算错。

### 19. 没跑 `pnpm validate` 就提交

坏数据会让 UI 直接崩。

### 20. 用 `material` 字段表达几何意图

`material` 只影响渲染颜色。想表达"这根梁是加强的"应该改 `size` 或用 `note`。

---

## 采购前的最终检查

- [ ] 型材是欧标还是国标？（配件不通用）
- [ ] 米重和单价跟供应商确认了吗？（公开资料可能差 15%）
- [ ] 所有连接件的系列都匹配吗？
- [ ] 螺栓长度对吗？
- [ ] 不锈钢吗？
- [ ] 角码数量 = 转角数 × 2？
- [ ] 端盖数量 = 外露端面数？（不是所有端面）
- [ ] 升降柱安装板孔距拿到了吗？
- [ ] 板材厚度与压条规格匹配吗？
- [ ] 加起来的总重量能搬动吗？
