# 05 · 升降桌专项

升降桌与普通桌最大的不同：**承重和升降靠外购的升降柱，不是铝型材。**

型材只负责做台面框体，把桌面板和升降柱连接起来。

## 结构分解

```
        桌面板（板材）
   ══════════════════════
    ┌──────────────────┐    ← 台面框体（铝型材，承上启下）
    │                  │
    └────┬────────┬────┘
         │        │
        ███      ███        ← 升降柱 ×2（外购件）
        ███      ███
         │        │
        ═══      ═══        ← 脚杯 / 底座
```

**三个部分各自独立选型**：

| 部件 | 谁做 | 决定什么 |
|---|---|---|
| 升降柱 | 外购 | 行程、承重、升降速度、噪音 |
| 台面框体 | 本项目设计 | 台面尺寸、刚性、与立柱的连接 |
| 桌面板 | 外购/定制 | 外观、手感 |

## 升降柱选型

### 关键参数

| 参数 | 常见值 | 说明 |
|---|---|---|
| **行程** | 500-700mm | 决定升降范围 |
| **承重** | 单柱 60-120kg | 双柱结构通常标 100-150kg |
| **节数** | 2 节 / 3 节 | 3 节行程更大，缩回更矮 |
| **安装板孔距** | 各有不同 | **必须核对**，决定框体怎么打孔 |
| **噪音** | < 50dB | 低于这个值基本无感 |
| **速度** | 25-38mm/s | 影响使用体验 |

### 一个必须核对尺寸

升降柱顶部有安装板，上面有螺栓孔。**孔距是各家自定义的**，常见 M8 螺纹孔，间距有 80×80、100×100、120×60 等等。

如果框体的梁位置和孔距对不上，就得加转接板。

**设计流程必须是：先定升降柱型号 → 拿到孔距图纸 → 再设计框体。**

### 行程与桌高

```
最高桌高 = 升降柱总长（全伸）+ 框体高 + 板厚
最低桌高 = 升降柱总长（全缩）+ 框体高 + 板厚
```

站立办公的建议高度：**1050-1150mm**（身高 170-180cm）
坐姿办公的建议高度：**700-750mm**

所以升降范围要覆盖 700 到 1150，行程至少 450mm。**选 3 节柱**才能做到，2 节柱通常只有 500mm 行程但缩回高度较高。

## 框体设计

### 为什么框体要做成"口"字形

单靠两根横梁连接两个升降柱，桌子会前后晃。做成闭合的框体（前后两根 + 左右两根），扭转刚度提升一个数量级。

```
   前梁 ─────────────
        │          │
   左端梁          右端梁      ← 这四根形成闭合框
        │          │
   后梁 ─────────────
```

**框体宽度 = 台面宽度 − 2 × 悬挑**
**框体深度 = 立柱安装板深度 + 2 × 余量**

### 台面悬挑

台面比框体宽多少？

- **左右悬挑**：建议 50-100mm。太多会导致边缘下垂（尤其站姿倚靠时）
- **前后悬挑**：建议 50-80mm。前方要留出腿部空间

1400 宽的桌，框体做 1300，左右各悬挑 50mm。

### 中横撑

两根立柱之间加一根横梁，作用是**抑制左右晃动**（人打字时的水平力）。

```
立柱内侧间距 = 立柱中心距 − 立柱宽度
中横撑长度 = 立柱内侧间距
```

**没有中横撑的升降桌，在最高位时会明显左右摇。** 这是必须的。

### 立柱与框体的连接

三种做法：

| 做法 | 强度 | 说明 |
|---|---|---|
| 立柱顶板直接用螺栓固定到框体 | 高 | 需要框体梁的位置与孔距对齐 |
| 角码连接立柱侧面到框体 | 中 | 灵活，但要注意角码不要挡住升降 |
| 转接板 | 高 | 孔距对不上时的标准解法 |

**注意**：角码不能安装在升降柱的**伸缩面**上（内管会刮到）。

## 桌面板

### 厚度

| 材料 | 推荐厚度 | 说明 |
|---|---|---|
| 实木 | 20-25mm | 重，需考虑承重 |
| 多层板 | 25mm | **性价比最高**，稳定不易变形 |
| 刨花板贴面 | 25-30mm | 便宜，但边缘容易吸水膨胀 |
| 竹板 | 20mm | 硬度高，环保 |

**25mm 多层板是升降桌的最优解**：刚性够、重量适中（约 16kg）、不易变形。

### 固定方式

**推荐：板材压条（PVC）** —— 桌面板四边嵌入框体的槽内，完全不打孔。

```
"ref": "panel-strip-pvc", "qty": 4.2    // 2×(1.4+0.7) 米
```

优点：可拆换、不破坏板材、边缘美观。

**备选：沉头螺栓** —— 需要打孔，但定位精确。适合需要严格对齐的场合。

## 稳定性检查清单

设计完成后逐条核对：

- [ ] 有中横撑吗？（没有 → 最高位会摇）
- [ ] 框体是闭合的吗？（不是 → 会前后扭）
- [ ] 每个转角有 2 个角码吗？（1 个 → 会转）
- [ ] 脚杯可调吗？（不可调 → 地面不平时会晃）
- [ ] 台面悬挑 ≤ 100mm 吗？（超过 → 边缘下垂）
- [ ] 升降柱的伸缩面没有被遮挡吗？
- [ ] 框体梁与升降柱安装板孔距对齐了吗？

## 常见错误

### 1. 只算铝型材，忘了升降柱的重量

升降柱单根 3-5kg，双柱就是 8kg。加上桌面板 16kg、型材 6kg，总重接近 35kg。

搬运和安装都要考虑这个重量。

### 2. 框体做成"日"字形而不是"口"字形

只有两根横梁没有端梁，扭转刚度差一个数量级。

### 3. 立柱与框体连接点太少

只靠立柱顶板 4 颗螺栓 + 没有侧向支撑，最高位会前后晃。

### 4. 忘记线缆管理

升降柱有电源线和控制线。升到顶时线要够长，降到最低时要能收起来。

**设计时留出走线空间**，或者直接买带线槽的型号。

### 5. 升降柱的底板与桌面框体干涉

有的升降柱底座比顶部安装板宽。装配时要确认底板不会顶到框体的梁。
