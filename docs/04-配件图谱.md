# 04 · 配件图谱

按功能分类。每项标注适配槽型 —— **系列不匹配就装不上**。

## 紧固件

### T 型螺母

槽内滑动，配合螺栓锁紧。分三种：

| 类型 | 特点 | 何时用 |
|---|---|---|
| **标准菱形 T 螺母** | 最便宜。必须从型材端头滑入 | 框架装配（装配时就穿好） |
| **弹片螺母** | 带弹片，可从槽口任意位置压入 | 后期加装、台面固定 |
| **四方螺母** | 无方向性，承压面积大 | 需要高强度的位置 |

```
"ref": "tnut-m8"         M8 标准菱形，适配 4040/4080/4545
"ref": "tnut-m6"         M6 标准菱形，适配 3030/4040
"ref": "spring-tnut-m8"  M8 弹片，可从任意位置压入
```

**经验**：能预估位置的地方用标准螺母（便宜），不能预估的用弹片螺母（灵活）。

### 螺栓

| 规格 | 配什么 | 长度选择 |
|---|---|---|
| M8×20 内六角 | 角码、配件固定 | 最常用 |
| M8×16 | 薄角码 | |
| M6×16 | 30 系型材 | |

**必须用 304 不锈钢。** 碳钢螺栓与铝型材接触会形成电偶腐蚀，一年后锈死拧不动。

### 垫片

弹簧垫片防松。振动环境（如带脚轮的架子）建议加。

## 外观件

### 端盖

封闭型材端面切口。

```
"ref": "cap-end-4040"
```

**数量**：每根外露型材的**两个端面**各一个。藏在角码里的端面不用。

升降桌的台面框体：4 根梁，其中 2 根短梁的外侧端面外露 → 需要 4 个端盖。

判断方法：**看这个端面是不是直接朝向外部**，被另一根型材挡住的不用装。

---

## 支撑件

### 可调脚杯

```
"ref": "foot-adjust-m8"
```

螺纹 M8 旋入型材中心孔（或立柱底部的螺纹板）。调节量约 ±10mm。

**为什么必须用可调脚**：地面几乎不可能绝对水平，尤其是地砖和木地板。不可调的脚会导致框架扭曲，门板对不齐、桌面摇晃。

**数量**：每个着地点一个。

### 脚轮

```
"ref": "caster-m10-2in"   2 寸 M10 万向带刹车
```

**注意**：
- 脚轮会增加高度（约 70-100mm），设计时要预留
- 4 个脚轮时的总承重 ≠ 单轮承重 × 4。要按 3 个轮承重算（有一个可能悬空）
- 带刹车的要用在至少 2 个轮子上

## 板材固定

### 板材压条（强烈推荐）

```
"ref": "panel-strip-pvc"
```

压入槽口后形成 U 型槽，板材直接插入。

**优点**：
- 板材**不需要打孔**
- 可拆换
- 板材边缘被包住，美观

**适用板材厚度**：常见规格适配 5mm / 8mm / 10mm

**用量计算**：

```
压条长度 = 板材每条嵌入边的长度之和
```

一块 1400×700 的桌面板，四边都嵌入 → 需要 2×(1400+700) = 4200mm = 4.2m

**注意**：用压条时，型材槽口的可用宽度会减少约 1mm，板材插入深度建议 ≥ 8mm。

### 沉头穿栓（替代方案）

板材打沉头孔 + 螺栓。优点是可精确固定位置，缺点是要打孔。见 [03 连接方式](./03-连接方式.md)。

## 清单核算方法

设计完成后，按这个顺序算配件：

```
1. 角码   = 转角数 × 2
2. T 螺母 = 角码数 × 2（每角码 2 颗）+ 其它螺栓固定点数
3. 螺栓   = 同上
4. 端盖   = 外露端面数
5. 脚杯   = 支撑点数
6. 压条   = 板材嵌入边长之和
```

**验证方法**：把这套数字代回 `design.json` 的 `accessories`，跑 `pnpm validate` 看是否通过。

## 一个真实的例子

1400×700×720 升降桌，4040 框体：

```
框体四角        → 外置角码 8 个（4 角 × 2）
                   T 螺母 16 个、螺栓 16 个
框体与升降柱    → 角码 4 个（每根立柱 2 个）
                   T 螺母 8 个、螺栓 8 个
外露端面        → 端盖 4 个（2 根短梁 × 2 端）
台面固定        → 弹片螺母 8 个
落地            → 脚杯 2 个（双立柱）
```

总计：角码 12、T 螺母 24、螺栓 24、弹片螺母 8、端盖 4、脚杯 2。

这与 `data/designs/standing-desk.json` 里的 `accessories` 一致。
