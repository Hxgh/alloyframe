# 02 · 截面与槽型

## 什么是 T 槽

铝型材的四面（或两面）开有沿长度方向的凹槽，截面像倒 T 字。作用是：**螺母可以在槽内任意位置滑动并锁紧**。

这就是"金属榫卯"的物理基础 —— 不用钻孔，不用焊接，螺栓 + T 螺母就能在任意位置建立连接。

## 槽口参数

本项目的 `profiles.json` 用六个参数描述槽型（单位 mm，指**全宽**，不是半宽）：

| 参数 | 含义 | 4040 典型值 |
|---|---|---|
| `open` | 槽口开口宽度 | 6.2 |
| `cavity` | T 腔最宽处 | 8.2 |
| `lip` | 唇口深度（开口处向内收的那段） | 1.5 |
| `neck` | 腔起始深度（唇口结束处） | 2.6 |
| `depth` | 槽全深 | 6.8 |
| `bore` | 中心孔直径 | 8.2 |

槽型剖面（从外向内）：

```
型材表面
  │        │          ← open（槽口 6.2）
  ├──┐  ┌──┤          ← lip（唇口 1.5）
  │  └──┘  │          ← neck（腔起始 2.6）
  │        │
  │        │          ← depth（槽全深 6.8）
  └────────┘
     cavity            ← 腔宽 8.2
```

T 螺母的宽度略小于 `cavity` 但大于 `open`，所以卡在腔内滑动、不会掉出来。

## 国标 / 欧标 / 8020 的差异

这是最容易踩的坑：**同名"4040"，不同标准的槽口尺寸不一样，配件不通用。**

| 标准 | 特征 | 识别方法 |
|---|---|---|
| **欧标**（本项目采用） | 槽口 6.2mm，腔 8.2mm，立面有弧形装饰槽 | 最常见。T 螺母是菱形 |
| **国标** | 槽口略窄（约 6.0mm），角更方 | 外观更"方正"，无弧形装饰 |
| **8020（美标）** | 英寸体系，配 1/4" 或 5/16" 螺栓 | 槽内有刻度线，编号如 40-4040 |

**采购时必须确认欧标或国标**，混用会导致 T 螺母卡死或松旷。本项目 `profiles.json` 默认采用欧标（`cavity: 8.2`）；如需国标型材，可在 `profiles.json` 中新增条目。

## 中心孔

型材中心的通孔，用于：

- 攻牙后直接做螺纹连接（M8 对应 8.2mm 底孔）
- 穿螺栓贯穿整根型材
- 空心减重（挤压工艺需要）

| 截面 | 孔数 | 孔径 |
|---|---|---|
| 2020 | 1 | ⌀4.2（M5 底孔） |
| 3030 | 1 | ⌀6.8（M8 底孔） |
| 4040 | 1 | ⌀8.2（M8 底孔） |
| 4080 | 2 | ⌀8.2 ×2 |

4040 的 ⌀8.2 孔正好是 M8 攻牙的标准底孔。这就是为什么 4040 常用 M8 五金。

## 槽的数量

| 截面 | 槽数 | 说明 |
|---|---|---|
| 2020 | 4（四面各 1） | |
| 4040 | 4（四面各 1） | 标准款 |
| 4080 | 4（长边 2、短边 1… 视厂家） | 有的做 6 槽 |
| 4545 | 4 | 槽口更大（10.2mm），配 45 系五金 |

**本项目渲染器按 `size` 自动判断**：长边（≥ 短边 1.6 倍）放两个槽，否则放一个。这与真实 4080 的常见做法一致。

## 槽口的可用范围

不是整根型材都能装东西：

- 两端各需留 ≥ 15mm（角码占位 + 加工余量）
- 槽内如果有拼接缝或标记，要避开

**设计时在 `note` 里写清安装位置的范围**，否则装配时会发现角码和螺母打架。

## 挤压方向与切口

型材是挤出件，沿长度方向的截面恒定。所以：

- 端面切口是平的（垂直切割）
- 斜切需要专门加工，成本高
- **转角的连接必须靠角码，不能靠型材自身成型**

这决定了框架设计的本质：**所有转角都是"两根直料的连接"，不是"一根料拐弯"。**

## 与本项目几何的关系

`src/lib/tslot.ts` 用 `profile.slot` + 零件的实际截面尺寸生成 `THREE.Shape`，然后沿长轴挤出。

关键约束（代码里已处理）：

- 槽深不能超过最小边长的 28%，否则挖穿
- 槽口宽度不超过最小边长的 16%
- 角料保留至少 18% 的边长

如果发现渲染出的型材看着"槽太浅"或"没有槽"，通常是零件 `size` 写得太小，触发了上面这些压缩规则。
