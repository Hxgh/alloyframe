# 07 · 典型 DIY 示例与连接审查

本章把“画出型材”“列出五金”和“说明两个零件怎样连接”区分开，给出三类**固定、开放、无运动机构**的 DIY 入门结构。三例统一采用 40 系 I 型槽 8，不迁移旧升降桌，不混用旧 `4040` 槽型假设。

> 三例是可检查的连接布置与计料示例，不是制造图、承重认证或安全防护设计。未证实的截面内部、角码尺寸、孔位、板材套件强度和价格均明确作为示意；没有额定载荷承诺。

## 1. 系统分析：从数据到连接，而非自动装配

| 层次 | 输入与职责 | 不负责的事情 |
|---|---|---|
| 型材与配件目录 | `profiles.json`、`accessories.json` 记录接口族、套件内含件及简化可视参数 | 不把估算值变成供应商 CAD 或采购保证 |
| 设计文件 | `parts` 描述构件，`accessories[].instances` 描述哪两个构件、安装位置与方向 | 不根据零件邻接自动猜测连接 |
| 共享数据校验 | 检查 Schema、引用、数量、接口和所支持角码的安装面等数据约束 | 不计算强度、抗扭、抗拔、预紧或施工公差 |
| 3D 视图 | 按世界坐标显示角码，拆解时跟随指定锚点 | 不自动配合求解、不移动其他零件、不自动重新布置连接 |
| 项目表单与 BOM | 配件详情只读说明实例；`qty` 是采购、计价的唯一数量 | 不把实例再算一次，也不重复计套内零件 |

旧文件没有 `instances` 仍可读取、编辑与计料，不会被自动补连接或转成 I8。没有实例意味着**只声明采购清单**，不表示已建立真实连接。

### 连接实例坐标合同

- 构件 `parts[].position` 仍为构件中心。
- 角码实例 `position` 是两个外安装面的**交线中心**，用装配态世界坐标，单位 mm；不是角码实体包围盒中心。
- `rotation` 是 Euler XYZ 角度，单位度，默认 `[0,0,0]`。渲染时转换为弧度。
- 角码实体沿局部 `+x`、`+y` 延伸，`z` 为宽度方向。
- `partIds[0]` 对应角码局部 `x=0` 安装面，`partIds[1]` 对应局部 `y=0` 面；顺序有意义。
- `anchorPartId` 必须是上述两构件之一，决定拆解视图跟随谁；装配态坐标本身不受拆解比例影响。
- 有实例时 `qty === instances.length`；一套结构件内的两颗螺栓、两只螺母不再单独收费。

工作台前左上梁的实际连接实例如下，仅节选该实例，完整文件仍有 16 套结构件：

```json
{
  "id": "top-rail-front-left",
  "position": [-360, 685, 280],
  "rotation": [-180, 0, 0],
  "anchorPartId": "post-front-left",
  "partIds": ["post-front-left", "top-rail-front"],
  "note": "局部 x=0 面贴立柱内侧，y=0 面贴梁底；+x 由柱朝梁中心，+y 朝下。"
}
```

对应立柱右内侧面为 `x=−380+20=−360`，梁底为 `y=705−20=685`，宽度中心为 `z=280`。此例说明安装面如何落位，不证明实际角码孔与槽腔、螺母和工具路径均已核对。

项目高级 JSON 可编辑这些实例；兼容 JSON Schema 的编辑器也可使用 `data/design.schema.json` 的字段提示。项目表单修改套件备注会保留实例；数量不一致会明确阻止应用。删除被引用构件须先移除或调整连接及数量；复制/镜像只生成零件，不复制连接。几何改动后若安装面不再有效，须修复共享校验错误，不会由软件自动搬动角码。

## 2. 共同接口与完整套件

### 已确认的厂家依据

1. [Motedis Profile 40x40L I-Type slot 8](https://www.motedis.com/en/Profile-40x40L-I-Type-slot-8)：40×40mm 截面，槽口 8mm、槽深 12mm，芯孔可加工 M8。可加工不等于出厂已攻牙。
2. [Motedis Bracket 40 I-Type slot 8](https://www.motedis.com/en/Bracket-40-I-Type-slot-8)：匹配紧固件选项为 **2 只 I8 M8 T 螺母 + 2 颗 DIN 912 M8×16**。采购时需选完整配置，不能默认裸角码自带。
3. [item T-Slot Nut 8 St M8](https://www.item24.com/en-gb/t-slot-nut-8-st-m8-bright-zinc-plated-2618)：提供 Line 8 / M8 / 镀锌钢的具体产品依据，说明槽型、螺纹与材料应分别识别；不据此宣称所有 40 / 45 系通用，也不承诺跨品牌互换。

目录中的 `4040-i8` 与 `connectionFamily: "i-slot-8"` 把这组连接体系与旧 `4040` 区分开。中心孔、槽腔、唇口、惯性矩、米重和价格等未证实部分仍为估算。当前截面渲染有槽深与槽腔安全裁剪，非 1:1 供应商截面 CAD。

### 结构套件与板材套件分开

| 套件 | 每套完整内容 | 用途 |
|---|---|---|
| `bracket-i8-kit` | 1 只二孔角码 + 2 颗 DIN 912 M8×16 + 2 只 I8 M8 T 螺母 | 梁与立柱 |
| `panel-i8-kit` | 1 只二孔角码 + 1 颗 DIN 912 M8×16 + 1 只 I8 M8 T 螺母 + 1 颗盘头木螺钉 + 1 只大平垫片 | 框梁与木板底面 |

软件采用的角码 36×36×30mm、厚 4mm、孔径 9mm 为**简化可视参数**，未声明取自制造商图纸。板材套件为项目示意组合，不是厂家原厂板材套装；3.5×10mm 木螺钉与 4.3×12×1mm 垫片须复核实际角码孔径、螺钉头搭接、板厚、预钻孔、边距与握钉力。按这些示意尺寸，入木约 `10−4−1=5mm`，不能仅因没有穿透 15 / 25mm 板就认为抗拔已合格。

每例结构套件均为 `两圈×每圈4根梁×每梁2端=16套`。它表示 16 个梁柱连接，不是“所有转角强制用双角码”。工作台额外 4 套板材件，双层架额外 8 套板材件；板材件不能从结构件中借计或遗漏。

## 3. 示例 A：固定工作台

- 项目入口：`/projects/workbench-i8`。
- 数据：[workbench-i8.json](../data/designs/workbench-i8.json)。
- 外廓：**800×600×750mm**，四柱、上下两圈，25mm 木台面。

| 构件 | 数量 | 下料尺寸与放置依据 |
|---|---|---|
| 立柱 | 4 | 725mm，`725=750−25`，底面 y=0、中心 y=362.5 |
| 宽向梁 | 4 | 720mm，`720=800−2×40`，夹在左右立柱之间 |
| 深向梁 | 4 | 520mm，`520=600−2×40`，夹在前后立柱之间 |
| 台面 | 1 | 800×600×25mm，板底 y=725、板中心 y=737.5、顶面 y=750 |

上框梁中心 y=705，顶面 y=725 承托板底；下框梁中心 y=200。总型材长度为 `4×725+4×720+4×520=7860mm`。角码装在梁底转角空腔，不在梁端面间，**不另扣两端角码厚度**。

连接清单：16 套结构角码 + 4 套独立台面固定件，共 20 个实例。台面件在前后梁的内侧、`x=±160` 四点固定；安装面一对应框梁、面二对应板底。

**制作前仍需**：验证台面挠度、水平力与抗扭、侧向稳定、板固定抗拔、底面防护与调平。示例的“固定”只表示无升降机构，不表示已经锚固地面。未建模的脚垫、端盖或锚固件不能当作已含。

## 4. 示例 B：双层置物架

- 项目入口：`/projects/shelf-i8`。
- 数据：[shelf-i8.json](../data/designs/shelf-i8.json)。
- 外廓：**600×400×900mm**，四根贯通立柱，两圈框梁，两块 15mm 木层板。

| 构件 | 数量 | 下料尺寸与放置依据 |
|---|---|---|
| 立柱 | 4 | 900mm，中心 y=450、底面 y=0 |
| 宽向梁 | 4 | 520mm，`520=600−2×40` |
| 深向梁 | 4 | 320mm，`320=400−2×40` |
| 上、下层板 | 2 | 各 520×400×15mm，宽度避开左右立柱占位 |

上圈梁中心 y=760，层板底 y=780、中心 y=787.5；下圈梁中心 y=120，层板底 y=140、中心 y=147.5。最高点为立柱顶面 y=900，不是层板面。总型材长度为 `4×900+4×520+4×320=6960mm`。

连接清单：16 套结构角码 + 每板 4 套、合计 8 套独立层板固定件，共 24 个实例。层板边界与立柱在示意中接触，实际需依据切割公差、装入路径和板材变形确定安装间隙，不能把零间隙模型当作施工公差。

**制作前仍需**：核对层板跨度与载荷、各层偏载、重心、抗倾覆与必要锚固、板侧抗拔。四根柱和两圈框不自动保证高处拉拽或重物偏放安全。

## 5. 示例 C：开放设备围框

- 项目入口：`/projects/enclosure-i8`。
- 数据：[enclosure-i8.json](../data/designs/enclosure-i8.json)。
- 外廓：**600×500×600mm**，四柱、上下两圈，**无封板、无门、无联锁**。

| 构件 | 数量 | 下料尺寸与放置依据 |
|---|---|---|
| 立柱 | 4 | 600mm，中心 y=300、底面 y=0 |
| 宽向梁 | 4 | 520mm，`520=600−2×40` |
| 深向梁 | 4 | 420mm，`420=500−2×40` |

上、下圈梁中心分别 y=580、y=80，总型材长度为 `4×600+4×520+4×420=6160mm`。16 套结构角码对应 16 个实例，没有板材安装套件。

这是空间占位与连接布置骨架，**不是机器安全防护罩**。没有切屑、激光、粉尘、噪声、电气或运动部件隔离能力，也不因名称“围框”而产生防护等级。若要增加面板、门、设备固定或联锁，应另做完整设计，不能视作本例已包含。

## 6. 旧升降桌：保留兼容，但不当作装配基准

`standing-desk.json` 仍保留原数据和采购式配件格式，本次不迁移、不静默修复。已知问题为：

1. **中横撑两端各 6mm 间隙**：内管内侧面为 `x=±466`，920mm 横撑端点为 `x=±460`。旧备注“内侧间距920”不等于实际内管间距932。
2. **缺顶部安装板和转接件**：柱管占位没有提供实际顶板外形、孔距与紧固路径。
3. **钢柱无 T 槽**：不能把 I8 或旧 T 螺母直接装在普通伸缩钢管侧面。
4. **板固定缺件**：只有若干弹片螺母，不是完整板侧螺栓、支架、木螺钉、垫片和加工方案。
5. **端盖备注方向错误**：实际外露的是前后长梁沿 X 的端面，不是短梁被长梁挡住的 Z 向端面。

详见 [05 升降桌专项](./05-升降桌专项.md)。旧文件中标注的额定载荷不因本次保留兼容或通过基础校验而得到验证。

## 7. 装配顺序与维护

先取得实际型材、角码、T 螺母和板材的图纸，核对接口、螺栓啮合长度与工具空间，再按以下顺序试装；此处不是供应商扭矩或工艺规范。

1. **共同准备**：按下料清单切割并去毛刺，区分上下圈梁。将角码、套内螺栓和匹配槽 8 螺母分装，不能以旧目录的通用 M8 螺母替换。先确认螺母是端部滑入式还是可后装式；滑入式须在封闭端部或装板前按各槽需要预穿，后装式按供应商方法确认旋转锁定与有效啮合。
2. **框架试装**：先将两组平面侧架松装，再用另一方向的梁合成四柱框。角码置于梁下与柱侧的直角空腔，不能夹在梁端面间。所有梁端对齐接触，复核两圈高度、对角线和垂直度，再按所选套件要求分步紧固；不在此提供未经核实的通用扭矩。
3. **工作台**：上框顶面和柱顶均为 725mm，检查台面支承后，从框内侧安装 4 个独立板挂接角码。最后放置台面，标记并预钻板底孔，核对垫片搭接和有效入木深度后安装，不能借用 16 套梁柱角码中的紧固件。台面未安装前完成框内不易触及的紧固。
4. **双层架**：先完成下层框与下板，再安装上层框与上板，或在框梁未完全锁紧前确定板的装入路径。每层各用 4 套板固定件。两板宽度避开贯通立柱，但零间隙示意不代替加工公差，不能强行敲入；最后复核层高、偏载与防倾倒要求。
5. **开放围框**：先装下圈再装上圈，确保底部角码仍高于地面。顶圈紧固与工具操作应在加装任何未来面板或设备之前完成；本例没有提供面板、设备固定或安全联锁，不把这些后续工作当作已完成。
6. **使用前复核**：检查全部 16 个梁柱接点及独立板固定点，核对螺母未空转、螺栓未顶底、板侧未穿透、角码未干涉。载荷、挠度、抗侧摆、抗拔与倾覆须另行验证；定期按供应商规定检查松动，不以展示模型替代试验。

## 8. 连接审查与验证路径

1. 在项目中检查装配态角码有无悬空、装反、与其他角码/板/柱干涉；切换拆解只辅助辨认锚点，不改变设计。
2. 打开“项目 → 项目配件 → 连接说明”，逐实例核对双方角色与 ID、备注、位置、旋转和完整套件。
3. 先从零件实际端面关系计算下料，另查角码与工具占位；不要额外统一扣两端角码尺寸。
4. 台面、层板、柱体、地面和设备固定分别列全，核对套内零件不重复、套外必要件不遗漏。
5. 编辑 JSON 后执行：

```bash
pnpm validate workbench-i8
pnpm validate shelf-i8
pnpm validate enclosure-i8
```

校验成功表示支持的数据约束通过，**不是可制造、额定承载或安全使用许可**。制作前仍须取得供应商图纸，复核孔位/槽腔/啮合/工具、板材孔与入木深度、预紧、防松、挠度、滑移、抗扭、抗拔、倾覆及实际使用环境。
