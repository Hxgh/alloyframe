## 选型速查

| 用途 | 推荐规格 | 说明 |
|---|---|---|
| 3D 打印机架、小型展示架 | 2020 | 跨度 < 500mm，轻载 |
| 工作台、书架、展示柜 | 3030 / 4040 | 30 系为常见性价比拐点 |
| 升降桌、设备机架 | 4040 | 承重与抗扭刚性均衡 |
| 大跨度横梁（> 1200mm） | 4080 | 抑制跨中下垂 |
| 重载龙门、自动化设备 | 4545 / 8080 | 高刚性重载 |

## 核心原则

1. **跨度与载荷共同决定截面**：相同均布线载荷、材料与截面下，简支梁挠度随跨度四次方（$L^4$）增长；换成集中载荷或总载荷不变时，不能照搬该比例。
2. **连接按实际构造计数**：没有“每角必定两个角码”的通则。三例按八根梁的两端共 16 套结构角码，板材另列完整套件；连接刚度与整体稳定性仍需核算。
3. **接口不能凭外形推断**：4040 不等于唯一槽型，同为 M8 不等于螺母与槽腔兼容；三例统一 I 型槽 8，不混用旧 4040 配件假设。
4. **空心外购件单列重量**：升降柱、脚轮等外购件须在 `parts[].massKg` 标注实重，不可用包围盒体积乘密度估算。
5. **区分数据来源**：`data/catalog/profiles.json` 中的 `source` 区分 `supplier` 与 `estimate`。当前仍用估算等级，部分已知官方尺寸不代表其余参数已认证；可视化、BOM 与数据校验都不代替制造、承载和安全评审。
